# 星序 Astra

一个可直接部署到 GitHub Pages 的中文星座与五行网站。全部出生资料在浏览器计算；无需后端、API Key 或构建步骤。

在线访问：[星序 Astra](https://ysd-hub.github.io/astra-star-map/)。

## 手机优先界面

首屏为大尺寸黑底星盘，白色页面与青色标签选中标记；“本命 / 运势 / 五行 / 星座”分别展示内容。出生资料在底部编辑面板内填写，支持安全区域和键盘缩小视口；电脑端使用星盘与解读双栏。星体标签支持触摸与键盘查看，密集文字避让时保留真实行星点位。

## 功能

- 出生日期、当地时间、出生城市或自定义经纬度 / IANA 时区。
- 太阳、月亮、上升星座；十颗行星位置、真实升降顶底四轴、可视化本命盘及整宫制落宫。
- 十二星座的性格特点、爱情表达、事业探索和自然宫位。
- 今日、明日、后天的星象指引，按日期切换，每天按北京时间自动更新。三日爱情与事业分别生成，同一天的内容在滚动日期窗口中保持稳定。
- 出生四柱、十天干日主、五行计数和木火土金水特征分析。
- 出生时间不详时，使用正午参考位置并省略上升、个人宫位、时柱。
- 手机适配、键盘交互、显式选择的本地保存与一键清除。

## 本地运行

在项目目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

访问 http://127.0.0.1:4173/，应出现黑底星盘，四个顶部标签可切换三日运势、五行和十二星座。ES Modules（JavaScript 模块）需要 HTTP 服务，直接双击 HTML 不适合作为预览方式。

计算验证：

```powershell
node test.mjs
```

成功时输出 `PASS`。检查覆盖时区、夏令时跳时与重复时刻、无效日期、上升点的东方地平线、四轴及中天子午圈、10 颗行星、整宫制、立春及跨时区节气、子正换日、时间不详、三日解读去重、日期稳定、五种相位及无相位、密集与黄经零点附近的标签避让。

## 计算口径

- 西方星盘采用热带黄道、地心位置。行星星历来自 Astronomy Engine 2.1.19；上升点依据当地恒星时、经纬度与黄赤交角计算。纬度范围为南北纬 66° 以内。
- 宫位采用 Whole Sign（整宫制）。白羊座对应自然第一宫等属于象征关联；个人第一宫由上升星座决定。
- 中天的赤经等于当地恒星时，天底与中天相差 180°；下降点与上升点相差 180°。四轴位置与整宫制宫头分别绘制。
- 八字历法来自 lunar-javascript 1.7.8。年、月柱以出生瞬间的节气划分；日、时柱按当地民用时间计算，使用子正换日，未校正真太阳时。临近节气且出生时间不详时，年、月柱也仅为正午参考。
- 五行按天干与地支本气的字数统计。未计藏干、节令权重、旺衰与喜用神，计数不等于命局强弱。
- 西方火土风水四元素与东方木火土金水五行分别呈现。十二星座与十天干没有统一的一对一对应。
- 三日运势以北京时间每日 12:00 的月亮、金星、火星、木星、土星与本命太阳的 0°、60°、90°、120°、180° 相位生成，容许度 6°，选取最紧密相位。星座通用运势使用该星座黄经中点，页面明确标示。文案属于固定象征规则的娱乐解读，事业内容为探索方向。
- 文案由“相位类型 + 北京时间实际日期”选择完整的标题、概述、爱情和事业组合。同一相位可连续出现，实际相位与容许度保持原值，每日行动建议分别呈现。浏览十二星座不会自动替换个人运势，只有点击对应运势入口才切换，且可一键恢复个人解读。
- 时区采用浏览器 Intl / IANA 数据库。夏令时造成重复时刻时，页面提示使用出生记录中的固定 UTC 偏移时区。

## GitHub Pages

将项目根目录推送到公开仓库，在 Settings → Pages 选择 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。根目录 `.nojekyll` 保证静态文件原样发布。

更新后推送到 `main` 即可自动重新部署。回滚时使用 `git revert <commit>` 并推送；停用公开网页可在仓库 Settings → Pages 取消发布。

## 文件与隐私

`index.html`、`styles.css`、`app.mjs` 为界面；`core.mjs` 为计算；`wheel.mjs` 为星盘绘制与标签避让；`data.mjs` 为中文解读和城市坐标；`vendor/` 为固定版本依赖。

表单不会上传或加入 URL。仅点击“记住资料”才写入此设备的 `localStorage`；点击“清除本地资料”删除本项目保存的资料并恢复示例。兼容旧版 `astra-birth-v1` 保存键。无账号、无追踪分析，界面使用系统字体。GitHub Pages 会处理常规访问日志。
