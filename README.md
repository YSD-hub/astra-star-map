# 星序 Astra

一个可直接部署到 GitHub Pages 的中文星座与五行网站。全部出生资料在浏览器计算；无需后端、API Key 或构建步骤。

## 功能

- 出生日期、当地时间、出生城市或自定义经纬度 / IANA 时区。
- 太阳、月亮、上升星座；十颗行星位置、可视化本命盘及整宫制落宫。
- 十二星座的性格特点、爱情表达、事业探索和自然宫位。
- 今日、明日、后天的星象指引，每天按北京时间自动更新。
- 出生四柱、十天干日主、五行计数和木火土金水特征分析。
- 出生时间不详时，使用正午参考位置并省略上升、个人宫位、时柱。
- 手机适配、键盘交互、显式选择的本地保存与一键清除。

## 本地运行

在项目目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

访问 http://127.0.0.1:4173/，应出现星盘、3 张运势卡片、5 个五行计数和 12 个星座按钮。ES Modules（JavaScript 模块）需要 HTTP 服务，直接双击 HTML 不适合作为预览方式。

计算验证：

```powershell
node test.mjs
```

成功时输出 `PASS`。检查覆盖时区、夏令时跳时与重复时刻、无效日期、上升点的东方地平线、10 颗行星、整宫制、立春及跨时区节气、子正换日、时间不详、三日运势跨日更新。

## 计算口径

- 西方星盘采用热带黄道、地心位置。行星星历来自 Astronomy Engine 2.1.19；上升点依据当地恒星时、经纬度与黄赤交角计算。纬度范围为南北纬 66° 以内。
- 宫位采用 Whole Sign（整宫制）。白羊座对应自然第一宫等属于象征关联；个人第一宫由上升星座决定。
- 八字历法来自 lunar-javascript 1.7.8。年、月柱以出生瞬间的节气划分；日、时柱按当地民用时间计算，使用子正换日，未校正真太阳时。临近节气且出生时间不详时，年、月柱也仅为正午参考。
- 五行按天干与地支本气的字数统计。未计藏干、节令权重、旺衰与喜用神，计数不等于命局强弱。
- 西方火土风水四元素与东方木火土金水五行分别呈现。十二星座与十天干没有统一的一对一对应。
- 三日运势以北京时间每日 12:00 的月亮、金星、火星、木星、土星与本命太阳的 0°、60°、90°、120°、180° 相位生成，容许度 6°，选取最紧密相位。星座通用运势使用该星座黄经中点，页面明确标示。文案属于固定象征规则的娱乐解读，事业内容为探索方向。
- 时区采用浏览器 Intl / IANA 数据库。夏令时造成重复时刻时，页面提示使用出生记录中的固定 UTC 偏移时区。

## GitHub Pages

将项目根目录推送到公开仓库，在 Settings → Pages 选择 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。根目录 `.nojekyll` 保证静态文件原样发布。

更新后推送到 `main` 即可自动重新部署。回滚时使用 `git revert <commit>` 并推送；停用公开网页可在仓库 Settings → Pages 取消发布。

## 文件与隐私

`index.html`、`styles.css`、`app.mjs` 为界面；`core.mjs` 为计算；`data.mjs` 为中文解读和城市坐标；`vendor/` 为固定版本依赖。

表单不会上传或加入 URL。仅点击“记住资料”才写入此设备的 `localStorage`；点击“清除本地资料”删除本项目保存的资料并恢复示例。无账号、无追踪分析。GitHub Pages 会处理常规访问日志；Google Fonts 提供可选字体，请求失败时使用系统字体，核心功能仍可运行。
